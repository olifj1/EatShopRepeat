# Meal Planner v1.0.5

Adds backup, device transfer and simple partner sharing.

- Export/import a full backup containing meals, plans, regulars and shopping state.
- Use the backup to move Safari data into the installed Home Screen app.
- Share the current meal-plan week as a small JSON file using the iPhone share sheet (with download fallback).
- Import a shared week; the required meals and ingredients are added/updated so its shopping list still works.
- Shared weeks are snapshots, not live two-way sync. Regulars, one-off shopping items and checked states remain personal.
