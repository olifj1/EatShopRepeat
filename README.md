# MealPlanner v1.0.42

Adds a direct cooking flow from saved meals.

- Meals that contain a cooking method now show a compact **Cook** button.
- Tapping **Cook** switches to the Cook tab and immediately opens that meal's ingredients and method.
- Closing the method leaves you on the Cook tab, where all saved recipes with methods remain available.
- The 12 starter Library recipes already contain cooking methods and can be used to test the flow after adding them to the household.
- No Firebase sync changes.
